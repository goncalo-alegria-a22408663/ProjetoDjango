Sobre esta Aplicação

1. Arquitetura MVT do Django

O padrão MVT (Model-View-Template) é a forma como o Django organiza o código:

  • Model — define as entidades e as suas relações; cada classe corresponde a uma tabela na base de dados (ficheiro models.py).
  • View — função em Python que recebe um pedido HTTP, consulta os Models necessários e devolve uma resposta (ficheiro views.py).
  • Template — ficheiro HTML com a linguagem de templates do Django ({% verbatim %}{{ }} e {% %}{% endverbatim %}) que define como os dados são apresentados.

Fluxo de informação: o utilizador faz um pedido HTTP → o Django consulta urls.py e identifica a View → a View consulta os Models e obtém dados da base de dados → a View injeta os dados num Template → o HTML renderizado é devolvido ao utilizador.
